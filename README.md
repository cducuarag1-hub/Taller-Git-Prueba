# Proyecto de Grafos en Java

## Descripción
Este proyecto implementa un grafo no dirigido utilizando listas de adyacencia en Java.

## Operaciones básicas
- Crear y agregar vértices.
- Agregar y eliminar aristas.
- Eliminar vértices.
- Buscar vértices.
- Mostrar la lista de adyacencia.
- Recorrido BFS (búsqueda en amplitud).
- Recorrido DFS (búsqueda en profundidad).

## Tecnologías utilizadas
- Java JDK
- Visual Studio Code
- Git y GitHub
